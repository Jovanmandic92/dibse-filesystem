# DIBSE File System

A Java project for the Software Engineering 1 course, implementing a small file-system model and several classic object-oriented design patterns.

## Features

The project demonstrates:

- **Singleton** – `IdGenerator` provides unique file IDs.
- **Factory** – `FileFactory` creates `TextFile` and `ImageFile` objects.
- **Observer** – antivirus scanners inspect files before they are added to a directory.
- **Composite** – `NewDirectory` can contain files and nested directories.
- **JUnit 5** – unit tests for the file factory.

## Design patterns

### Singleton
`IdGenerator` uses the Singleton pattern so that file IDs are generated by one shared instance.

### Factory
`FileFactory` hides the creation of concrete file types from the caller:

```java
AFile file = fileFactory.createFile("text", "example.txt");
```

### Observer
`Directory` can register antivirus scanners. Before a file is added, the registered scanners inspect its content.

### Composite
`NewDirectory` represents a directory that can contain files as well as other directories, allowing a tree-like file-system structure.
